## О проекте

Kernvox — приложение для системных администраторов, разрабатываемое в рамках **Samsung Academy**. Проект создаётся как практический инструмент для мониторинга серверной инфраструктуры и отображения ключевых метрик работы системы.

Основная цель — предоставить администраторам простой и понятный интерфейс для контроля текущего состояния серверов и сервисов без избыточной сложности и перегруженности функциями.

---

## Назначение

Kernvox визуализирует базовые метрики серверной инфраструктуры:

- **аптайм серверов** — время непрерывной работы узлов;
- **доступность сервисов** — актуальный статус критичных компонентов;
- **состояние хостов** — работоспособность узлов инфраструктуры;
- **оперативная статистика** — сводные данные для быстрой оценки ситуации.

Приложение не заменяет полноценные системы мониторинга, но даёт администратору быстрый обзор текущего состояния инфраструктуры в одном месте.

---

## Целевая аудитория

Kernvox рассчитан на:

- **системных администраторов** — для повседневного контроля инфраструктуры;
- **DevOps-инженеров** — для оперативного мониторинга состояния сервисов;
- **специалистов технической поддержки** — для диагностики проблем;
- **небольшие команды** — которым нужен простой инструмент без избыточной сложности.

---

## Зачем это нужно

В реальной работе системному администратору часто нужен не «большой комбайн», а инструмент, в который можно быстро зайти и увидеть:

- какие хосты сейчас доступны;
- сколько времени работает сервер без перезагрузки;
- есть ли проблемы с конкретными сервисами;
- где ситуация требует немедленной реакции.

Kernvox решает именно эту задачу: даёт администратору понятную картину текущего состояния инфраструктуры без необходимости разбираться в сложных интерфейсах или настраивать десятки параметров.

## Архитектура проекта

Проект состоит из двух связанных компонентов:

```
┌─────────────────┐         HTTP/REST          ┌─────────────────┐
│   KernvoxHub    │ ─────────────────────────► │    Kernvox      │
│  (серверный хаб)│         JSON API           │ (Android-клиент)│
└─────────────────┘                            └─────────────────┘
       │                                              │
       ▼                                              ▼
  Сбор метрик                                   Отображение
  с серверов                                    в интерфейсе
```

- **KernvoxHub** — серверный компонент, который собирает метрики с мониторингуемых серверов и предоставляет их через REST API
- **Kernvox** — Android-приложение, которое получает данные от KernvoxHub и отображает их в удобном интерфейсе

## Технологии

### Клиент (Android)
- **Язык:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Архитектура:** MVVM
- **Сеть:** Ktor Client
- **Сериализация:** kotlinx.serialization
- **DI:** Внедрение зависимостей через конструктор

### Сервер (KernvoxHub)
- **Язык:** Kotlin
- **Фреймворк:** Ktor Server
- **API:** REST/JSON

### Сборка
- **Система сборки:** Gradle (Kotlin DSL)
- **Минимальная версия Android:** API 24 (Android 7.0)
- **Целевая версия Android:** API 36
- **JVM:** Java 11

## Установка и запуск

### Требования
- Android Studio (последняя версия)
- JDK 17 (для сборки)
- Android SDK с API level 36

### Клонирование репозитория

```bash
git clone https://github.com/Vennilay/Kernvox.git
cd Kernvox
```

### Запуск в Android Studio

1. Откройте проект в Android Studio
2. Дождитесь завершения синхронизации Gradle
3. Запустите на эмуляторе или реальном устройстве

## Сборка проекта

### Команды сборки

```bash
# Сборка debug APK
./gradlew assembleDebug

# Сборка release APK (с оптимизацией и ProGuard)
./gradlew assembleRelease

# Запуск unit-тестов
./gradlew test

# Запуск instrumentation тестов
./gradlew connectedAndroidTest

# Очистка проекта
./gradlew clean

# Установка на подключённое устройство
./gradlew installDebug
```

### Варианты сборок

| Вариант | Описание | Minification |
|---------|----------|--------------|
| **Debug** | Для разработки и отладки | Отключён |
| **Release** | Для публикации | Включён (R8 ProGuard) |

### Оптимизации сборки

Проект использует следующие оптимизации для уменьшения размера APK и улучшения производительности:

- **R8 Full Mode** — полная оптимизация байт-кода
- **ProGuard** — удаление неиспользуемого кода
- **Parallel Compilation** — параллельная компиляция Kotlin
- **Build Cache** — кэширование результатов сборки

## Безопасность Android-клиента

- Пароль локальной блокировки приложения не хранится в открытом виде: сохраняются только случайный salt и PBKDF2-хеш.
- `apiKey` и `actionKey` сохраняются в Preferences DataStore только в зашифрованном виде. Шифрование выполняется через AES/GCM/NoPadding, ключ AES создаётся и хранится в Android Keystore.
- `actionKey` используется только для опасных действий, например перезагрузки сервера. Если включена блокировка приложения, перед отправкой такой команды требуется подтверждение паролем приложения или биометрией.
- В release-сборке для обычных адресов KernvoxHub требуется HTTPS. HTTP допускается в debug и для локальных адресов разработки (`localhost`, `127.0.0.1`, `10.0.2.2`).
- Android backup отключён для приложения, чтобы DataStore с секретами не попадал в резервные копии.
